# 요구사항별 구현 상태

[PRD](prd/AgentAgency_PRD.md)의 각 요구사항을 다음 네 가지로 구분합니다.

- **완료**: 구현했고 자동 테스트나 실제 연동으로 확인했습니다.
- **부분**: 일부만 구현했거나, 실서비스 검증이 남았습니다.
- **미구현**: 아직 구현하지 않았습니다.
- **공식 지원 미확인**: 공급자의 공식 자동화 지원을 확인하지 못해 비활성으로 두었습니다.

기능별 사용법은 [기능 안내](features.md)에 있습니다.

| 사용량 모니터링 | 완료 | 영구 실행 기록 기반 집계(`/usage`), 에이전트·팀 성과 지표 |

## 운영 전에 남은 검증

1. Codex CLI와 Codex Cloud에 로그인한 뒤 `aa verify codex-cli`(또는 `aa config` → AI 구독)를 실행합니다.
2. 실제 Telegram 봇·포럼 그룹과 GitHub로 `aa setup`의 스모크 테스트를 실행합니다.
3. ARM64 서버에서 `install.sh`를 실행합니다.
